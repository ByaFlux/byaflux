# ByaFlux 0.1.15

- Linux integrado à versão estável, com instaladores x86_64 e ARM64 na release principal.
- FakeAccount carrega perfis sem depender do seletor nativo de contas e oferece um seletor visual próprio.
- Acesse FakeAccount pelo próprio perfil, pelo botão na barra superior ou nas informações do plugin.
- As configurações e os temas da edição Linux anterior são importados quando não existem na instalação estável.

- Fotos de perfis copiados usam o ID de origem, mantendo o ID real da conta conectada.
