ByaFlux 0.0.7 para Discord — Windows x64.

Esta versão inclui o ProfileBadges, o badge changer visual do ByaFlux.

- Escolha badges visuais para o seu próprio perfil.
- Selecione níveis de Nitro e Server Boost por ícones.
- Arraste pela alça de quatro pontos para mudar a ordem, com animação suave.
- As seleções atualizam imediatamente no painel e são salvas por conta.
- Abra “Set badges” pelo clique direito no seu usuário, pelo painel inferior esquerdo ou abaixo de Orbs no menu da conta.
- Restaure as badges reais com um botão.

As alterações do ProfileBadges são locais: somente você as vê. Elas não concedem Nitro, benefícios ou badges reais do Discord. O ByaBadges oficial continua independente.

Baixe **ByaFluxInstaller.exe**, feche completamente o Discord, inclusive o ícone perto do relógio, e escolha Install.
Quem usa a versão de produção pode atualizar pelo ByaFlux. Instalações de desenvolvimento por pnpm usam os comandos de build e injeção.
