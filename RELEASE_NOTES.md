# ByaFlux 0.1.26

- Corrigido o salvamento de imagens e outros itens ao criar vários perfis no ProfilePreset.
- Confirmação de propriedade das badges pela autorização oficial do Discord, com retorno automático ao ByaFlux, sem digitar código no site.
- BetterNitroGem: gemas animadas de Boost, incluindo as do FakeBadges, preservando o card nativo e o tamanho padrão das badges.
- Mantidos os controles nativos de badges e o painel de personalização do ByaFlux.

Windows, Linux x86_64 e ARM64. Inclui Android 0.2.14 com a correção de perfis e BetterNitroGem.

A confirmação automática de perfil no Desktop exige atualizar a hospedagem para a API 1.3.2. Preserve `.env`, `ENCRYPTION_KEY` e `data` ao atualizar.
Perfis cujas imagens já foram perdidas precisam ser salvos novamente.
