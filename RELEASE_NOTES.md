# ByaFlux for Linux (dev-version)

Versão experimental para Linux x86_64 e ARM64. Base: ByaFlux Desktop 0.1.12.

- Instalador CLI e arquivos compilados no Linux.
- Catálogo atual de plugins do ByaFlux, Equicord e Vencord incluído.
- Configurações locais em ByaFluxLinuxDev, separadas da versão estável.
- Atualizações consultam somente releases linux-dev-v. Esta versão não substitui a release estável do Windows.
- Instalação normal do Discord e descoberta de Flatpak. Snap não é suportado.
- Áudio, captura de tela, Wayland e integrações externas precisam de teste no seu ambiente. A presença de um plugin no catálogo não garante compatibilidade de todas as funções.

Feche o Discord antes de instalar ou remover. Para remover o mod, execute o mesmo instalador com --uninstall.
