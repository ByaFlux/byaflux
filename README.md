# ByaFlux

<img src="assets/byaflux.png" alt="Logo do ByaFlux" width="120">

Plugins e personalização para o aplicativo do Discord, com recursos próprios do ByaFlux e plugins das bases Equicord e Vencord.

**[Baixar para Windows x64](https://github.com/ByaFlux/byaflux/releases/latest/download/ByaFluxInstaller.exe)** · [Ver versões](https://github.com/ByaFlux/byaflux/releases)

## Requisitos

- Windows de 64 bits.
- Aplicativo do Discord instalado.
- Conexão com a internet para instalar e receber atualizações.

## Instalação

1. Baixe o **ByaFluxInstaller.exe** pelo botão acima.
2. Feche completamente o Discord, inclusive o ícone perto do relógio.
3. Abra o instalador, selecione sua instalação do Discord e clique em **Install**.
4. Abra o Discord e acesse **Configurações do usuário → ByaFlux**.

Os instaladores publicados atualmente são para Windows x64.

## Plugins

Abra **ByaFlux → Plugins** para escolher os recursos que deseja usar. O filtro **Show ByaFlux** mostra os plugins próprios do projeto.

- **ProfileBadges:** permite escolher e ordenar as badges exibidas no seu próprio perfil. Essas alterações são visuais e aparecem apenas para você.
- **ByaBadges:** exibe as badges oficiais do projeto nos perfis. É obrigatório e já vem ativo.

## Atualizações

Quando houver uma nova versão, uma faixa aparecerá no topo do Discord com o botão **Atualizar e reiniciar**.

Ao clicar, o ByaFlux baixa e aplica a atualização e reinicia o Discord. Se a atualização falhar, ele não reinicia.

Você também pode verificar atualizações em **ByaFlux → Updater**. Se precisar atualizar manualmente, baixe o instalador mais recente e use **Reinstall / Repair**.

## Backup

Use **Backup & Restore** nas configurações do ByaFlux para exportar ou restaurar suas configurações.

Backups do ByaFlux, Vencord e Equicord são aceitos. A importação não instala plugins que não estejam incluídos no ByaFlux. Reinicie o Discord após restaurar um backup.

## Reparar ou remover

Feche completamente o Discord e abra o instalador:

- **Reinstall / Repair:** reinstala ou repara o ByaFlux. Use também se ele desaparecer após uma atualização do Discord.
- **Uninstall:** remove o ByaFlux da instalação selecionada.

Depois, abra o Discord novamente.
